What it does

Chat with the models you choose
OpenAI, Anthropic, Google, DeepSeek, Moonshot, Zhipu, MiniMax, xAI, Mistral, Groq, OpenRouter, Together, Fireworks, or any OpenAI-compatible server, with your own account.
Work with your projects
Add a folder or upload files. The app indexes them so answers cite the right file.
An agent that does the work
It reads, searches, edits files and runs PowerShell commands in a folder you pick. Every change can wait for your approval, and edits can be undone.
A worklog you can follow
Each step the agent takes shows as a clear row you can open. Plans, decisions and results are kept per project.
Long chats stay usable
A context meter shows how full the conversation is. It compacts itself at 80%, keeping the details that matter.

Measured, not guessed

Praxis gives the model exact facts about your code instead of whole files, and checks its work. That lets a cheap model do work you would expect from an expensive one. Every figure here comes from a benchmark run.

How the agent works

Praxis Chat has two agent engines. You pick one per chat, and both run on whichever model provider you connect.

Telos

Beta

Praxis's own agent engine, built into the app.

Real tools on your files
Read, search (glob and grep), write and edit files, and run Windows PowerShell commands, including long ones as background jobs you can check on and stop.
You stay in charge
Every change and command follows the chat's edit mode.
Approve
Everything waits for you.
Auto
Safe commands run, the rest waits.
Bypass
Everything runs.

Rules you write add to that, for example "always allow git status" or "never read *.env".

Hard limits no rule can lift
The agent stays inside the folder you chose, never touches secret files or the .git folder, writes a plan before it changes anything, and you can undo every edit.
Steady on long tasks
Reads run side by side to save time. Guards stop a model that keeps repeating the same call.

Praxis Harness

The full-featured engine for long, many-step work. Every model call goes through your own providers, and Praxis's approvals and rules sit in front of every tool it uses.

Helpers
The agent hands side work, such as a wide search or a review, to helper agents running alongside it.
Goals
The agent keeps working round after round until a goal you set is met.
Plan mode
The agent plans with read-only tools and changes nothing until you approve the plan.
Workflows, worktrees, code navigation and terminals
Some are switched on in Settings.

Context that holds up

The context meter shows how much of the model's window a chat uses. At 80% the chat compacts itself into a detailed summary: the goal, the work done, open hypotheses and the current step. The summary is kept, so a long task carries on after a restart.

Your data stays on your PC

Chats, projects, files and settings are stored locally. Prompts go only to the provider you connect, for the chats that use it.

  • No account with us. Anonymous usage counts only, never your content, and off with one click.
  • API keys are kept in Windows Credential Manager, never in plain files.
  • The only other requests the app makes are a check on GitHub for new versions and those anonymous counts.

Install

  1. Download the installer, Praxis-Chat-Setup.exe. It is always the latest version. Its SHA-256 is at the top of this page.
  2. Run it. If Windows shows a SmartScreen warning, click More info, then Run anyway. The app installs and opens; there is nothing else to install.
  3. On the setup screen, connect a model provider with your own API key, or your Google Cloud account.

Questions

Is it free?

Yes. Praxis Chat is free to download and use during the beta, for personal and work purposes. Any charges for model use come from the provider you connect, under your own account.

Which models can I use?

Bring your own provider account. You can connect OpenAI, Anthropic, Google, DeepSeek, Moonshot, Zhipu, MiniMax, xAI, Mistral, Groq, OpenRouter, Together, Fireworks, or any OpenAI-compatible server. Use an API key, or your Google Cloud account for Google.

Windows says "Windows protected your PC". What do I do?

Windows may show a SmartScreen warning because our code-signing certificate is still being issued. Click More info →then Run anyway. Signed builds ship soon.

Does it update itself?

Yes. The app checks GitHub for new versions and updates itself when one is released. That check sends nothing about you or your data, beyond what any download sends (your IP address and app version).

Where is my data?

On your PC, in %APPDATA%\PraxisChat. That holds your chats, projects, files, memories and settings. API keys are kept in Windows Credential Manager.

What do I need to run it?

Windows 10 or 11, 64-bit, about 1 GB of free disk space, and an internet connection to reach your model provider. Everything else is in the installer.

How do I give feedback?

Open an issue on GitHub Issues. Please include your app version (in Settings) and the steps to repeat the problem. Never paste API keys or private data into an issue.
