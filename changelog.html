Changelog

What shipped in each release, newest first. The app updates itself, so you get each release when it comes out.

  1. 0.4.0

    5 November 2026

    A calmer look, and the agent's commands rebuilt from the ground up: a real shell per chat, safer permissions checked part by part, a sandbox, Git Bash next to PowerShell, model routing across your providers, and web pages on any provider.

    A calmer look

    • The input bar is one rounded card: your text on its own row, then + (images, @ mentions, / commands, ! commands, earlier prompts, your editor), the mode pill, the model with its effort in one picker, and Send.
    • The sidebar has New session, Open folder and New project at the top, then each project as a folder with its chats under it.
    • The header holds only what you change often: Local, the engine and a light/dark button. Answer style, Lead and Export are in the ⋯ menu. It fits a narrow window.

    Commands and the terminal

    • One shell per chat: the folder carries over between commands, and a trusted project's .praxis/env.ps1 runs first.
    • PowerShell 7 first, UTF-8 throughout, PowerShell errors counted as failures, and common bash forms such as 2>/dev/null rewritten. Git Bash as a second shell on both engines when Git for Windows is installed.
    • A command that reaches its time limit moves to the background instead of being killed. Long output goes to a file; the agent gets a preview and the first error.
    • Esc and Stop end the whole command, child processes included, within a second.
    • Monitors: the agent can watch a running command's output or a WebSocket and get each new line as it arrives.
    • A command log: every command leaves a row with its shell, folder, output file, and whether it ran, asked or was refused, and why. Settings has a Commands section, and /doctor checks your shells.
    • A file the agent viewed with a command counts as read; an edit still applies when the file changed meanwhile, as long as its old text is there exactly once; files that are not UTF-8 are refused with the encoding named.

    Safer commands

    • Each part of a command is judged on its own: read-only commands never ask, injection tricks always ask, and a short blocked list is refused. Heredocs are read in full, so nothing hides behind one.
    • Allow this pattern on a waiting command saves a rule such as npm run * for that project, for PowerShell and Git Bash alike.
    • A secrets wall: keys and tokens are kept out of every agent command's environment and masked in its output; a command that reads, copies or names a secret file never runs.
    • A sandbox: agent commands run with a restricted Windows token and limits, never write inside .git or .praxis, and never touch SSH keys, browser profiles or credential stores. Network for agent commands can be limited to an allow list per project, and a chat's commands can be given a memory limit.

    Model routing, off until you turn it on

    • Turn on Auto in new chats in Settings, Model routing: Praxis sorts each task into a class and picks a model from the providers you connected, a fast model for small checked edits and your frontier model for hard work. Each reply says which model it used and why, and you can pin a model per class.
    • It learns per project from how tasks went (tests, your thumbs, retries), works within token budgets, skips models that are down, and shows each routed reply's tokens and how much less it used than sending everything to your frontier model.
    • The lead run gives each piece its own model and steps up one tier after a failed attempt. A second opinion from another model is there if you want it; it is off by default.
    • For page and UI work, Praxis can draft several versions, check them by code and let you pick one.

    Web and code knowledge

    • The agent reads public web pages on any provider, as Markdown with citations. Local and private addresses are refused. Details in the privacy note.
    • Faster meaning search, better Python symbols from Pyright, and rename across files in the agent engine.

  2. 0.3.0

    3 November 2026

    The biggest update so far: work alongside the agent, safer permissions, six more languages, a lead that plans for cheaper models, and your own hooks, MCP servers, skills and agents.

    Working with the agent

    • One mode pill in the input bar: Manual, Accept edits, Auto and Plan, with Alt+M to step through them. Bypass asks you to confirm. Local chats can use every mode.
    • Auto mode: edits that can be undone run on their own; anything that cannot be undone (a force push, a publish, git reset --hard, deleting many files) asks you first; everything else gets a quick check by your background model, and if the check cannot run, Praxis asks you.
    • Comments on approvals, kept by the agent as corrections.
    • Type while the agent works: your next message waits in a queue, Esc stops the reply without losing what you typed, and the queue stays with its chat.
    • Background commands, and a Tasks list of running shells and workers, with each one's output kept in .praxis/tasks.
    • @ to point at a function or class, and / or Ctrl+K for commands such as /context, /rewind, /btw, /init and /doctor.
    • Side questions with /btw that stay out of the chat, and rewind to an earlier reply: the code, the chat, or both.
    • Branch a chat from any message, export it as JSONL, and merge a worktree chat back once its tests pass.
    • A transcript view with folded tool runs, what the model saw for each reply, and a Changes panel with undo for one hunk at a time.
    • Notes after a reply: a changed function signature and how many places call it, a passing test with no assert, a test run that ran no tests.
    • Windows notifications when a reply finishes or waits for you, with an off switch.
    • Live status in the sidebar (working, waiting for you, done), with worktree chats grouped.
    • One plan per project that all its chats read, editable in the project's Plan tab.
    • Output styles: Concise, Normal, Explain or Teaching, per chat or per project.

    Bigger tasks with cheaper models

    • A lead with cheap workers: a frontier model plans, cheaper models build each piece, and code checks every piece before it is accepted. The lead's and the workers' tokens are shown separately. Off by default for now.
    • Workers on the Praxis engine: the agent hands a piece of work to a worker that runs as its own hidden chat, under the same approvals, at most four at a time.
    • Prompt caching: each step of a long turn reuses most of the previous prompt, so it costs less. The context meter shows the cached share.
    • An effort picker in the input bar sets how much the model thinks.

    Code knowledge

    • The code map now covers C#, Java, Go, Rust, C and C++, and lists definitions for PHP, Kotlin, Ruby, Lua and Scala.
    • /init writes a PRAXIS.md for your project from the code map.
    • Praxis reads a project's PRAXIS.md, CLAUDE.md, AGENTS.md and .cursorrules, and keeps a memory for each project.
    • Long chats are summarised in steps, and /context shows what fills the context window.

    Safety and permissions

    • Folder trust: a project's own instructions, hooks, MCP servers, skills and agent files load only after you trust its folder.
    • Rules from settings files: managed, then yours, then the project's, then your local ones. A repository's own file can only make Praxis ask or refuse, never allow.
    • Model lists show only the providers you connected with a key, and the default model follows them. A chat whose provider is gone says so instead of sending your message to another provider.

    Extend Praxis

    • Hooks: Claude Code-style hook tables on both engines; a PreToolUse hook can block a step. Edit your own hooks in Settings.
    • MCP servers over stdio from trusted projects; the first start of each server always asks you. Details in the privacy note.
    • Skills and agents from .praxis and .claude folders.
    • The praxis command line works with the running app: praxis -p "<prompt>", praxis index, praxis verify, and praxis review for your local changes, with a security mode. Routines run through Windows Task Scheduler.
    • /doctor checks this PC (long paths, disk space, Git, PowerShell) and offers one-click fixes.

    Look and feel

    • System, Light or Dark theme.
    • A list of keyboard shortcuts, and a status line under the input bar.
    • A calmer chat header, with the per-message controls in the input bar.

  3. 0.2.2

    1 November 2026

    Projects for every chat, and Local: the agent on your whole PC.

    Projects and Local

    • Every chat is in a project. Chats that had no project move into a new built-in project, Local. Nothing is deleted.
    • Local works on the whole PC: it starts in your home folder, reads and changes files on any drive and runs commands. It never reads .ssh, browser profiles or saved credentials. Commands that wipe a disk, partitions or backups are always refused, and deleting more than 20 files, or anything outside the current folder, asks you first, in every edit mode.
    • Open a folder as a project: drag it onto the window, or use "Open folder".

    Agent

    • Web search on the chat's own provider: Claude chats search with Anthropic's web search and Gemini chats with Google Search. Your provider may charge for each search.
    • Missing developer tools (Node.js, Python, Git, the .NET SDK and others) are installed for you, with winget or from the tool's official site. Details in the privacy note.
    • Command output streams in steadily, and a short line shows what the agent is doing.
    • Fixed "database is locked" errors when several agent chats run at once.

  4. 0.2.1

    28 October 2026

    Anonymous usage data, and thumbs on replies.

    Usage data

    • Anonymous counts of how the app is used, so we know which features help: never your messages, files, file names, project or chat names, keys or error messages, and your IP address is not stored. On by default; a notice on first start, and one click to turn it off there or in Settings, Privacy. Details in the privacy note.
    • Thumbs up or down on replies, and a short 1 to 5 question at most once a month.

  5. 0.2.0

    28 October 2026

    Knows your code, and checks its own work.

    Large projects

    • Any folder can be your workspace, however big. Large ones index the most useful files first, and the agent can still read and search every file.
    • More build and dependency folders are skipped by default. Add a .praxisignore file to skip others.

    Understands your codebase

    • An exact index of your functions, classes and methods in Python, TypeScript and JavaScript, with their line ranges and where each one is used. Built on your PC.
    • New agent tools to outline a file, open one function, list its callers and search code, so the agent reads far less and guesses less.
    • Renames a function or class across the whole project in one approved change, with one undo. Uses it is not sure of are listed, never changed.
    • Notices files you change, between messages and while it works, and never edits a file it has not seen in its current state.

    Checks its own work

    • Function names and file:line references in an answer are checked against the index before you see it. Claims like "the tests pass" are checked against what actually ran.
    • Runs the tests it names with your project's own command, and counts "0 tests ran" as a failure.
    • A type check after each edit, listing only the problems that edit added.

    Better with smaller models

    • The app gathers the relevant code before the model starts, including code named in an error's stack trace.
    • On our benchmark with DeepSeek V4.1 Flash, agent tasks pass more often (97%, up from 84%) with about a third of the input tokens.
    • Long chats keep the exact code facts they found when they are summarised.

    Fixes

    • Listing the files in a subfolder could report 0 files.
    • The first-start setup screen showed a second scrollbar.
    • Several chats running at once could hold the database too long.
    • The agent engine now runs as praxis-engine.exe, so tools that stop every Node process no longer stop it.

  6. 0.1.0

    23 October 2026

    First public beta.

    Install and updates

    • One Windows installer with everything inside. No Python or Node.js to install.
    • Updates itself from GitHub, and copies your database to a backup before a new version opens it.

    Your own models

    • Connect OpenAI, Anthropic, Google (Gemini API key or Google Cloud), DeepSeek, Moonshot, Zhipu, MiniMax, xAI, Mistral, Groq, OpenRouter, Together, Fireworks, or any OpenAI-compatible server, with your own account.

    Projects

    • Add a folder or upload files, including PDF and Word documents.
    • A project map of folders, main files and their symbols.
    • Optional semantic search once you pick an embedding model.

    An agent that does the work

    • Praxis Harness, the default engine: helper agents, goals, plan mode, workflows, worktrees, code navigation for TypeScript and Python, and terminals.
    • Telos Beta, Praxis's own engine: reads, searches, writes and edits files, and runs PowerShell commands, including long ones as background jobs.
    • You stay in charge: Approve, Auto and Bypass modes, your own allow, ask and deny rules, hard limits no rule can lift, and undo for every edit.
    • A worklog of each task's plan, steps, decisions and results.

    Long chats

    • A context meter, and automatic compaction at 80% into a detailed summary that survives a restart. /compact runs it by hand.

    Privacy

    • Chats, projects, files and settings stay on your PC. Prompts go only to the provider you connect.
    • API keys are kept in Windows Credential Manager. No telemetry, no analytics, no account.

    Look and feel

    • The Orbit logo, with a comet that circles while the model thinks and a closing ring when a reply is done. Light and dark themes.

Every installer and its SHA-256 is on GitHub Releases. Suggestions and bug reports: open an issue.
